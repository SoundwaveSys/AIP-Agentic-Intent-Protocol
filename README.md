# AIP Jinni — PayPal Agent Trust

A local prototype for the **Agentic Intent Protocol (AIP)** and its first reference experience, **Jinni**.

## Vision

Humans currently browse commerce sites, compare products, and check out themselves. In the agentic internet, users will increasingly tell AI agents what outcome they want and allow those agents to act.

AIP is designed as a vendor-neutral trust and authorization layer:

**Human Intent → Agent Capability → Authorization → Payment → Intent Receipt**

Jinni is the reference AI agent experience. PayPal is the first payment/trust integration concept.

## Current V1

- Jinni command interface
- Future-of-commerce landing experience
- Example use cases
- Product comparison simulation
- Intent verification
- PayPal Agent Trust payment simulation
- Security Center
- AIP developer page
- Protocol primitive overview

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

> Current payment interactions are simulated. No real PayPal credentials or payments are used.
